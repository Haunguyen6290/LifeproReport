BƯỚC 0. Chuẩn bị

1
Công ty tạo một tài khoản GitHub miễn phí tại github.com (bấm Sign up, nhập email, mật khẩu, tên tài khoản). Nên dùng email chung của công ty.
2
Công ty gửi tên tài khoản GitHub (ví dụ: congtyb-it) cho chủ phần mềm.
Bảo mật: chủ phần mềm chỉ chia sẻ code. Tuyệt đối không gửi các file .env.local, .env.vercel hay file backup dữ liệu cho bên khác.

3.3 Điền địa chỉ web

Vercel sẽ cấp một địa chỉ, ví dụ https://lifepro-report-congtyb.vercel.app.

1
Vào Vercel, chọn Settings, rồi Environment Variables. Thêm biến NEXT_PUBLIC_SITE_URL với giá trị là địa chỉ web ở trên.
2
Vào tab Deployments, bấm dấu ⋯ ở dòng trên cùng rồi chọn Redeploy.
3
Vào Supabase, chọn Authentication, rồi URL Configuration. Dán địa chỉ web vào ô Site URL và bấm Save.

BƯỚC 4. Tạo tài khoản Admin đầu tiên (công ty làm)

Phần mềm đăng nhập bằng tên đăng nhập. Bên trong, hệ thống đổi tên đăng nhập thành email dạng tendangnhap@congty.local. Tài khoản Admin đầu tiên phải tạo bằng tay như sau:

4.1 Tạo người dùng

Vào Supabase, chọn Authentication, rồi Users. Bấm Add user và chọn Create new user.

Authentication › Users › Create new user

4.2 Gán quyền Admin

Vào SQL Editor, bấm New query, dán đoạn lệnh dưới đây rồi bấm Run:

insert into public.profiles (id, username, full_name, role_id, must_change_password)
select u.id, 'admin', 'Quản trị viên', r.id, false
from auth.users u, public.roles r
where u.email = 'admin@congty.local' and r.name = 'ADMIN';

Kết quả đúng là “Success. 1 row affected”.

BƯỚC 5. Kiểm tra và cập nhật về sau

5.1 Kiểm tra

✓
Đăng nhập được, các menu mở ra bình thường.
✓
Thử tải ảnh đại diện. Nếu lỗi, vào Supabase, chọn Storage, xem đã có các bucket chưa (các bucket này được tạo khi chạy đủ 60 file ở bước 2.2).
✓
Việc backup tự động (GitHub Actions) sẽ không chạy vì chưa có khóa. Vào repo của công ty, chọn tab Actions, rồi bấm Disable workflow để tắt nếu không dùng.

5.2 Lấy bản cập nhật mới từ chủ phần mềm

Mở repo congtyb-it/LifeproReport, bấm Sync fork rồi bấm Update branch. Vercel sẽ tự cập nhật web sau khoảng 3 phút.

github.com/congtyb-it/LifeproReport

This branch is out-of-date

Khi bản cập nhật có file migration mới (ví dụ 0061_…sql): chủ phần mềm sẽ báo cho công ty biết. Công ty cần chạy file đó trong SQL Editor như bước 2.2 trước khi bấm Sync fork.
